# Assignment 2 — Advanced CSS

This project was created for Assignment #2: Advanced CSS.

The purpose of the assignment is to practice modern CSS layout techniques using **Flexbox** and **CSS Grid**.

## Tasks

### Task 0 — Navigation Bar

A navigation bar created using Flexbox with:

* Logo on the left
* Navigation links on the right
* Horizontal alignment
* Spacing between links

### Task 1 — Card Row

A row of cards created using Flexbox.

Each card contains:

* Image
* Title
* Description
* Button
* Hover effect

### Task 2 — Grid Page Layout

A page layout created using CSS Grid with:

* Header
* Sidebar
* Main content
* Footer

The layout uses `grid-template-areas` to organize the page structure.

### Task 3 — Image Gallery

A gallery containing nine images created using CSS Grid.

The gallery includes:

* Three equal-width columns
* Consistent gaps
* Image captions
* Hover effects

### Task 4 — Portfolio Page

A portfolio page combining Flexbox and CSS Grid.

The page contains:

* Navigation bar
* Projects section
* Sidebar
* Project cards
* Footer

## Technologies

* HTML5
* CSS3
* Flexbox
* CSS Grid
